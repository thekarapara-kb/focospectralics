
# Documentation

Monographs and comparative benchmark audits.

## Files


| File                       | Type              | What it covers |
| ---------------------------- | ------------------- | ---------------- |
| `astronomy-monograph.html` | Monograph         | Optical sub-threshold phase recovery, image enhancement, and survey telemetry integration. |
| `cosmology-monograph.html` | Monograph         | Tetrahedral aperture partitions, Hubble-frame comparison, energy-budget calculations, and bounded-origin curvature. |
| `astronomy-comparison.md`  | Comparative audit | Compares the described zero-mode image and NEO residual methods with standard optical/CCD processing. |
| `cosmology-comparison.md`  | Comparative audit | Compares the described conic cosmology calculations with standard ΛCDM baselines. |

## Reading order

Start with the framework's geometric and conservation concepts in
[`../engines/README.md`](../engines/README.md). Read
`cosmology-monograph.html` before `cosmology-comparison.md` for the cosmology
method and its comparison, then `astronomy-monograph.html` before
`astronomy-comparison.md` for the image and survey applications.
